# Jotacode Homebrew Tap

Homebrew tap for Jotacode apps and tools.

## Setup

```bash
brew tap codejota/tap
```

## Kaset Discord Rich Presence

A fork of [Kaset](https://github.com/sozercan/kaset) with Discord Rich Presence integration.

Project: https://github.com/codejota/kaset-discord-rich-presence

Install:

```bash
brew install --cask kaset-discord-rich-presence
```

Update:

```bash
brew update
brew upgrade --cask kaset-discord-rich-presence
```

Uninstall:

```bash
brew uninstall --cask kaset-discord-rich-presence
```

## Available packages

Casks are stored in [`Casks`](./Casks) and command-line formulae in [`Formula`](./Formula).
